## What you can do

- Publish a page or blog post
- Unpublish content (archive)
- Understand what visitors see on the public site

## Who this is for

- **Publisher**, **Admin**, and **Owner** roles
- Editors — to know when content goes live (publishers usually handle publish)

<Callout type="info">
  **Editor** can create and save drafts, but **Publish** is only available to users with publish permission.
</Callout>

***

## Step 1: Finish the draft

1. Open the page or post in the editor.
2. Check title, body, and the **SEO** tab.
3. Wait for **Saved** in the header — the draft is stored.

***

## Step 2: Publish

1. Click **Publish** in the editor header.
2. Confirm if prompted.
3. Status changes to **Published**.

> 📌 The live site usually updates within a few seconds. If you don't see changes, refresh the browser (F5).

***

## Step 3: Check the public site

Open the site in a new tab (open-site icon in the dashboard or copy the URL):

| Content type | Where to view |
| ------------ | ------------- |
| Page | `/{workspace}/{site}/{page-slug}` |
| Blog post | `/{workspace}/{site}/blog/{post-slug}` |
| Home | `/{workspace}/{site}/` |

You'll see the published title and body with the same styling as in the editor.

***

## Draft vs published

| Status | Who sees it |
| ------ | ----------- |
| **Draft** | Your team in the panel only |
| **Published** | All public site visitors |
| **Archived** | Hidden from site, kept in panel |

Edits to published content go to the **draft** first. Click **Publish** again for visitors to see updates.

***

## Versions and revert

Before large edits:

1. Open **Versions** in the editor.
2. Click **Create snapshot** — saves a copy of the current draft.
3. If something goes wrong — pick a snapshot and **Revert to this version**.

Revert only changes the **draft**. Publish again to update the live site.

***

## If something isn't working

- **No Publish button** — ask an admin for the Publisher role or to publish for you.
- **Old version on site** — refresh; confirm you clicked Publish after the latest edits.
- **Page 404** — check slug and that status is **Published**, not Draft.
- **SEO not updated** — wait a minute; search engines may take hours or days to re-index.
