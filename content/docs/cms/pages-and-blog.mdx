## What you can do

- Create static pages (About, Contact, etc.)
- Write blog posts with headings, lists, code, and video
- Set SEO for each page or post
- Save versions and roll back to a previous state

## Who this is for

- **Editors** — create and edit drafts
- **Publishers** — plus publish to the live site

***

## Site pages

### Step 1: Open the page list

1. Select a site under **Sites**.
2. Go to **Pages**.
3. You'll see a table: title, slug, status (draft / published).

### Step 2: Create a page

1. Click **New page**.
2. Enter **title** and **slug** (URL segment: `/{site}/{slug}`).
3. The **full-screen editor** opens.

### Step 3: Write content

In the page body:

- Type like in a normal document.
- Press **`/`** — block menu: headings, lists, quote, code, image, YouTube video.
- Select text — toolbar appears: bold, italic, link, color.
- Drag blocks by the **handle on the left** to reorder.

Drafts **autosave** every few seconds. The editor header shows the last saved time.

### Editor sidebar

| Tab | Contents |
| --- | -------- |
| **Content** | Block structure (outline) |
| **SEO** | Search title, description, keywords, social preview image |
| **Media** | Insert images from the library |
| **Versions** | Snapshots and revert |

***

## Blog posts

### Step 1: Open the blog

1. In the site menu, choose **Blog posts** (or **Content**).
2. Filter by site if you have several.

### Step 2: Create a post

1. Click **New post**.
2. Enter a **title** — slug is filled automatically (you can edit it).
3. Write in the same editor used for pages.

Published posts appear at:

`/{workspace}/{site}/blog/{post-slug}`

If the site home is a blog feed, posts may show on the home page directly.

***

## After saving

- The draft stays in the panel — visitors **cannot** see it.
- Status stays **Draft** until you click **Publish** (see [Publishing](/docs/cms/publishing)).
- A version **snapshot** saves a copy before large edits.

***

## If something isn't working

- **Editor won't open** — check that you're signed in and can **create content**.
- **Slash menu doesn't appear** — click an empty line and type `/` at the start.
- **Lost text** — open **Versions** and revert the draft to a snapshot.
- **Image won't insert** — upload the file in the **Media** tab or site media library first.
