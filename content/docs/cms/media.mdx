## What you can do

- Upload images and insert them into pages and posts
- Store site files (PDFs, documents) in the file manager
- Pick an image for SEO and social sharing (Open Graph)

## Who this is for

- Editors — images in articles
- Admins — downloadable files on the public site

***

## Media library (images)

### Step 1: Open the library

1. Select a site under **Sites**.
2. Go to **Media** (or open the **Media** tab in the editor).

### Step 2: Upload a file

1. Click **Upload** or drag files into the window.
2. Wait for upload to finish — the file appears in the grid.

Supported formats: **JPG, PNG, WebP, GIF**.

### Step 3: Insert into content

**From the editor:**

1. **Media** tab on the right — pick an image.
2. Or type `/` in the body and choose **Image**, then select from the library.

**From the formatting bar:**

- Drag and drop an image into the editor area.

After insert, resize by dragging the corners on the page.

***

## SEO image

In the editor **SEO** tab:

1. **OG image** field (social preview).
2. Choose a file from the media library.
3. Save the draft and publish.

Shared links in messengers will show the selected preview.

***

## Site file manager

**Files** in the site menu — documents visitors can download (reports, PDFs, attachments).

### Upload

1. Open **Files**.
2. Click **Upload** and choose a file.
3. The file gets a public path on the site.

### Delete

Select a file and **Delete** — the download link stops working.

<Callout type="warning">
  Do not upload confidential documents to the public file manager — anyone with the link can download them.
</Callout>

***

## What happens next

- Images are available in the editor immediately.
- On published pages, images show with the alt text you set.
- **Files** are available at the site URL after upload.

***

## If something isn't working

- **Upload stuck** — check file size; compress the image and try again.
- **Image missing on site** — republish the page after inserting the image.
- **File 404** — confirm the file wasn't deleted and the site URL is correct.
- **No Media section** — you need site access in the workspace; contact an admin.
